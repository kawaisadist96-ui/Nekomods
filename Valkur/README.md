# Valkür

CK3 Valkür karakter/asker modu için çalışma alanı.

**Durum:** Yerel proje ve gelişim kayıtları bu klasöre aktarıldı. Büyük model dosyaları Git LFS kullanır; klonlama sonrasında `git lfs pull` çalıştırın.

- Güncel model: `work/vanilla-integration/valkur-vanilla-equipment.blend`.
- Borulu sahne: `work/vanilla-integration/valkur-vanilla-preview.blend`.
- Gelişim raporları: `CURRENT-STATE.md`, `work/vanilla-integration/INTEGRATION-NOTES.md`, `work/recovery/RESTORATION-NOTES.md`.
- Mevcut test modu: `mod/valkur_units_test/`; yanındaki `.mod` launcher dosyasının yolu taşınabilir olarak `mod/valkur_units_test` yapıldı.
- Kaynaklar ve eski çalışmalar: `source/`, kökteki `.blend` dosyaları ve `work/` altındaki bütün ara kayıtlar.
- Dosya envanteri ve SHA256: `TRANSFER-MANIFEST.json`.

Kullanıcının son oyun testinde diğer animasyonlar çalıştı; kalkan tutuşu ve kılıcın beldeki yeri açık sorun. Bu sürüm kusursuz/nihai oyun modeli olarak sunulmaz. Windows/Blender/CK3 yolları başka makinede uyarlanmalıdır. Kaynaklara yeni bir lisans verilmemiştir; oyun kaynaklarına ait haklar sahiplerinde kalır.

Bilinen kullanıcı geri bildirimleri: yürüyüş/diz hareketi, kalkan tutuşu, kılıç yerleşimi. Ayrıntılar için ../KNOWN_ISSUES.md ve ../PROJECT_STATUS.md dosyalarına bakın.
