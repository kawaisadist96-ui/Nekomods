# CK3 Models / Mesh Models

Bu klasör CK3 modlarında kullanılan özgün 3D mesh modellerinin (.glb) ortak deposudur.

## Yüklenmesi beklenen dosyalar
- higanbana.glb
- Kidemlivalkur.glb
- valkur.glb

Bu README dosyasının oluşturulması, GLB dosyalarının yüklenmiş olduğu anlamına GELMEZ. Büyük ikili modelleri Git LFS ile yükleyin ve GitHub'da varlıklarını doğrulayın.

## Ajanlar için
- İşe başlamadan önce kökteki START_HERE.txt dosyasını okuyun ve başlangıç raporu/onay kuralına uyun.
- Kaynak model dosyalarını silmeyin veya üzerlerine yazmayın; değişikliklerde sürüm ve test bilgisi tutun.
- Blender/CK3 içe aktarma testlerinin sonuçlarını HANDOVER.md ve PROJECT_STATUS.md'ye kaydedin.
