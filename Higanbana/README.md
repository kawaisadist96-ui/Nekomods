# Higanbana

CK3 Higanbana karakter/animasyon modu için çalışma alanı.

**Durum:** Bu klasör başlangıç kaydıdır; gerçek model ve animasyon kaynakları henüz burada doğrulanmadı.

Planlanan hareketler: öne eğik ninja koşusu, kunai hareketleri, kaçınma ve yakın dövüş animasyonları. Uygulama ve oyun içi test sonuçları ayrıca kaydedilecektir.
